# Sample taxonomy — emergent jailbreak classes (benign proxy)

Generated by `refusalclimb run` (seeds=20, budget=200, fanout=4) on the fully-offline
benign forbidden-token proxy. Each "class" is a cluster of successful prompts that share a
dominant **softening framing** — the lever the refusal-guided search learned to pull to walk
the (benign) refusal boundary. The number of well-separated clusters is a coarse **novelty
metric**: more distinct framings means the search surfaced more *kinds* of bypass, not just
variants of one.

> ⚠️ Benign proxy only. These "framings" are harmless surface tokens (`hypothetically`,
> `fictional`, `roleplay`, …) used to lower a deterministic refusal-strength score for the
> harmless token `BANANA`. They are **not** real jailbreaks. See `DISCLOSURE.md`.

## How a class is defined

- Each successful prompt is mapped to a small, deterministic feature embedding
  (`refusal_signal.refusal_embedding`) — offline, a one-hot on the prompt's dominant softening
  token. On the real-model path this becomes a `sentence-transformers` embedding.
- Prompts are clustered greedily by cosine distance (`archive.Archive.cluster`). On the
  real-model path this becomes HDBSCAN with a silhouette/novelty score per cluster.
- A cluster's **label** is read off its centroid's dominant axis, so labels are always
  consistent with membership.

## What counts (rigorously) as a "new class"

In the real-model setting, a cluster qualifies as a *new* class when it is (a) well-separated
in embedding space (silhouette above a threshold), (b) **not** reachable by the binary baseline
within the same query budget, and (c) **transfers** to at least one held-out model. The offline
proxy demonstrates the machinery for (a); (b) and (c) are part of the `# TODO(real):` path.
